# 麦麦要换头像

让 bot 每天定时从头像库随机抽取一张图片更换 QQ 头像的 MaiBot 插件。

需要安装 `maibot-team.snowluma-adapter`（SnowLuma 合并版适配器）或 `maibot-team.napcat-adapter`（NapCat 适配器）**之一**：两者都提供 `adapter.napcat.account.set_qq_avatar` 接口，插件无硬性适配器依赖，运行时自动探测可用接口。

## 功能

- **每日随机换头像**：每天到达触发时间（默认 08:30，可叠加随机漂移）后，从头像库随机抽取一张图片，按配置处理成 1:1 后更换 QQ 头像；每天最多更换一次（含跳过的情况）。
- **`/msa add` 命令**：引用一条含图片的消息发送，即可把图片加入头像库。
- **`change_avatar` 工具**：bot 在聊天中被用户明确要求"换个头像"时可自行调用；带每日次数上限与冷却，不可用时工具自动从模型面前隐藏。

## 头像库

- 插件数据目录（宿主分发的 `data/plugins/<插件>/`）下的 **`image` 子文件夹**是默认头像库。
- 可在配置中追加一个**额外读取路径**（绝对路径，正反斜杠均可识别，允许混用，例如 `C:\Users\Administrator\Desktop/image`）。
- 支持 png / jpg / jpeg / gif / webp / bmp；动图取第一帧。
- 换头像时按配置把非 1:1 图片处理成 1:1（默认**居中切割**，可选**拉伸**），最长边超过 1024px 会等比缩小后上传。
- 每日随机抽取范围 = 数据目录 image 文件夹 ∪ 额外路径（两处重复文件按路径去重）。

## 命令

| 命令 | 说明 |
|---|---|
| `/msa add` | 引用一条含图片的消息发送；用图片内容哈希命名，相同图片不会重复入库 |
| `/msa add 头像1` | 同上，但按指定名称保存；同名文件直接覆盖 |
| `/msa debug random` | 强制立即随机换一次头像（调试用；不影响当日每日计划，也不占工具配额与冷却） |
| `/msa` | 显示用法 |

命令可回复图片消息使用，也支持本条消息直接带图；被引用消息里有多张图时取第一张。

## LLM 工具

`change_avatar`（无需参数）：从头像库随机抽一张换上。仅在用户明确要求换头像时调用。
工具按状态动态暴露：

- 配置关闭"允许 bot 调用工具换头像"、或今日次数达到上限（默认 2 次/天）、或冷却未过（默认 5 小时）时，工具会被禁用（模型看不到）；
- 恢复可用后自动重新暴露。
- 工具换头像的次数与冷却只统计工具调用，每日定时更换不占工具配额。

## 配置项

### 插件（所有插件默认配置项）

| 项 | 默认 | 说明 |
|---|---|---|
| enabled | `true` | 是否启用插件 |
| config_version | 与插件版本同步 | 配置版本（自动维护，无需修改） |

### 核心配置

| 项 | 默认 | 说明 |
|---|---|---|
| square_mode | `居中切割` | 图片不是 1 比 1 时的处理方式：`居中切割` / `拉伸` |
| extra_dir | （空） | 额外读取路径，绝对路径，正反斜杠均可；留空只使用数据目录 image 文件夹 |

### 每日随机头像

| 项 | 默认 | 说明 |
|---|---|---|
| enabled | `true` | 是否启用每日随机换头像 |
| trigger_time | `08:30` | 触发更换的时间（24 小时制 HH:MM），按 bot 所在机器的本地时间 |
| drift_spec | `"-45"-"30"` | 触发时间随机漂移范围（分钟）。格式固定为 `"a"-"b"`：两侧必须带英文双引号、中间用 `-` 连接，缺引号或缺中间的 `-` 视为格式错误（不收，回退默认值）；负数代表向前（提前）漂移 |
| skip_probability | `0.5` | 跳过今天换头像的概率（0~1，每天到达触发时间时掷一次） |

### 工具选项

| 项 | 默认 | 说明 |
|---|---|---|
| allow_bot | `true` | 是否允许 bot 调用工具换头像；关闭时工具不暴露 |
| daily_limit | `2` | 工具每天调用上限（次，0 表示当天不允许调用） |
| cooldown_hours | `5.0` | 工具调用冷却时长（小时） |

## 状态与重试

- 状态保存在插件数据目录的 `state.json`：今天的计划时间、结果、工具用量等；跨重启保留。
- 计划时间到达时若更换失败会自动重试，连续 3 次失败则当天放弃。
- 插件在计划时间之后才启动/启用时，会在启动后补做当天的一次更换（同样掷跳过概率）。

## 依赖

- QQ 适配器**二选一**（无硬性插件依赖，启动时自动探测 `adapter.napcat.account.set_qq_avatar` 接口）：
  - `maibot-team.snowluma-adapter`（SnowLuma 合并版适配器），或
  - `maibot-team.napcat-adapter`（NapCat 适配器）
- Python 包：`Pillow`（1:1 处理）、`aiohttp`（图片链接下载）

> 两个适配器同时安装时，插件按全名优先使用 SnowLuma 合并版适配器的接口。

## 安装

把本目录放入 MaiBot 的 `plugins/` 下，重启 MaiBot。适配器需已配置并连接 SnowLuma 客户端。
